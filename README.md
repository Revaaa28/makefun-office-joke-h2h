Entry for make.fun's "The Funniest Office Joke, Judged Head to Head". The program writes a single one-line office joke (103 characters) to /output/entry.txt:

> I told my manager I was blocked, and she unblocked me by adding me to a meeting about being blocked.

## Run it

```sh
python3 main.py
```

By default the line is written to `/output/entry.txt`. Set the
`MAKEFUN_OUTPUT` environment variable to write somewhere else, e.g.
`MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py`.
